# No Metrics View

Browser extension to hide viewer counts, social metrics, bot messages, and unwanted UI clutter across Twitch and X (Twitter).

## Features

### Twitch
- **Hide Go Live Button**: Hides the dashboard "Go live" stream button without disrupting the layout.
- **Hide Bot Messages**: Automatically hides chat messages from StreamElements and SoundAlerts (7TV).
- **Hide Viewer Counts**: Works universally across all languages/locales (live channels, cards, side nav, and VOD/clip views).
- **Hide 7TV Raid Viewers**: Hides raid viewer numbers in 7TV raid notification banners.

### Twitter / X
- **Hide Replies Counter**
- **Hide Likes Counter**
- **Hide Retweets Counter**
- **Hide Bookmarks Counter**
- **Hide Views Counter**

### Extension UI
- **Section Controls**: "All on" / "All off" bulk toggles for each category.
- **Instant Updates**: Toggle metrics without refreshing open pages.
